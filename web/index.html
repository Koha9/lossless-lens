读图说明与分析口径 ＋

频谱：整首音频使用 Hann 窗、最多 8192 点 FFT、50% 重叠；先分别计算每个声道的功率，再平均，避免反相立体声被抵消。平均功率转换为相对 dB，每首歌的频谱峰值为 0 dB。

时频图：横轴为时间，纵轴为频率，颜色表示相对功率。全曲压缩到最多 320 个时间格和 513 个频率格，每格保留最大能量；3D 再压缩至最多 128 × 129 格以保持交互流畅。悬停读数代表显示格，不代表未压缩的瞬时值。

对比：2D 叠加频谱并分面显示时频图；3D 将曲目放在独立层上，时频图高度表示曲目编号，不是响度。使用相同坐标范围和 −120 至 0 dB 色阶；较短曲目、较低采样率以外的区域为空。可切换为相对进度对齐不同长度曲目。

归一化与限制：频谱与时频图分别按各曲目的各自峰值归一化，因此适合比较形状，不能用于比较绝对响度。静音显示为底噪色并单独标记。截止频率沿用项目的启发式检测；低通、老录音或母带处理也会造成截止，不能单凭图表判断有损转无损。此页面提供频谱摘要，不代替 CLI 的位深和完整鉴定报告。
